# 🍕 Delicious Pizza Sales Dashboard

## 📌 Project Overview

The Delicious Pizza Sales Dashboard is an interactive Power BI project designed to analyze pizza sales performance and provide meaningful business insights through data visualization.

The dashboard helps users understand sales trends, product performance, customer ordering patterns, and overall business performance.

## 🎯 Project Objective

The main objective of this project is to analyze pizza sales data and create an interactive dashboard that helps businesses monitor sales performance and identify high-performing products and trends.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Data Analysis
* Data Visualization
* Power Query
* DAX
* Business Intelligence

## 📊 Dashboard Features

* Total Sales Analysis
* Total Orders
* Total Pizzas Sold
* Average Order Value
* Sales trend analysis
* Pizza category analysis
* Pizza size analysis
* Product performance analysis
* Interactive filters and slicers

## 📈 Key Insights

The dashboard provides insights into:

* Overall sales performance
* Best-selling pizza categories
* Popular pizza sizes
* Product-wise sales performance
* Order trends
* Revenue patterns
